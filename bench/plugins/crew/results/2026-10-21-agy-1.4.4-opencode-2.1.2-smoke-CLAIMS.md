What opencode 2.x changed, from probes:

- Plugins are `export default { id, setup(ctx) }` with
  `ctx.tool.hook("execute.before", e => …)`; the v1 named export with
  `"tool.execute.before"` is ignored silently.
- Throwing inside `execute.before` blocks the tool, and the message reaches the
  model. The shell tool is named `shell` and also passes through
  `execute.before`.
- A plugin listed in `OPENCODE_CONFIG_CONTENT` or in an `OPENCODE_CONFIG` file
  (absolute path or `file://`) did not load. One in `.opencode/plugins/` of the
  working directory, or in `$OPENCODE_CONFIG_DIR/plugins/`, did.
- Runs hung intermittently at server start (`serve --stdio` logged
  "cli starting" and nothing more) — with and without a plugin, with shared and
  isolated storage — then worked minutes later. Cause not found.
