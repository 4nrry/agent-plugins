**Smoke notes, not run records.** Grok Build 1.0.77 (it updated itself from
1.0.70 on 2026-11-05), grok-4.7, n=1 per case, one throwaway repo trusted for
the batch and untrusted after it. Logs stayed in the session scratchpad and
were not committed.

## What 1.0.71 to 1.0.77 changed for crew

Read in Grok's own changelog (`~/.grok/CHANGELOG.md`, none marked breaking) and
in a diff of `--help` between the two binaries: no flag crew passes changed,
`grok inspect --json` has the same keys, and the events crew reads (`system`
init, `assistant`, `result` with `is_error`) are unchanged. Additions crew does
not use yet: hooks accept `"failClosed": true` (1.0.71); a headless run stopped
by SIGTERM now ends its stream with a closing record (1.0.74; crew's own
timeout still fails the run); `context_window` from `config.toml` no longer
falls back after an idle spell or a failed request (1.0.74); `grok usage
--json` prints the plan's limit (1.0.77 help).

## The bug both versions share

`--tools` takes tool IDs. crew passed `run_terminal_command`, the shell's name
as the model and the hooks see it; its ID is `run_terminal_cmd`. Grok prints
`--tools "run_terminal_command" names no tool, so other tools stay available`
and drops the whole list. Probed on both binaries with an unknown model id,
which fails before any request: 1.0.70 and 1.0.77 behave the same. The same
held for `ask --web`, whose `x_*` entries name no tool either.

| Case | Tools offered (init event) | stderr |
|---|---|---|
| delegate, crew 0.15.0 | 22, image and video generation, workflow and web fetch included | the warning |
| delegate, crew 0.15.1 | the 7 listed plus `search_tool`, `use_tool` | empty |
| `--web`, crew 0.15.0 list | 23 | the warning for the four `x_*` names |
| `--tools web_search,web_fetch` | `search_tool`, `use_tool`, `web_search`, `web_fetch` | empty, but the worker reported no X search |
| `--web`, crew 0.15.1 (`--disallowed-tools`, no `--tools`) | the same four | empty; X search ran as a backend tool |

In every delegate run the guard still denied what crew does not list, so the
extra tools were offered, never used.
